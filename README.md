# Stimuler Growth Audit

**Live → https://eddieatadapty.github.io/stimuler-flow-rebuild/**

Five ideas to turn more Stimuler users into subscribers, each built into a clickable version of Stimuler's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Make the paywall about their Band 7.0 | +10–20% CR to purchase |
| 02 | Let them speak before they sign up | +5–10% CR to purchase |
| 03 | Put Arjun’s 7.5 where they decide | +5–10% CR to purchase |
| 04 | Ask for reminders after the paywall | +5–10% CR to purchase |
| 05 | On ✕, offer the free trial you already sell | +5–10% ARPU |

Every price, rating and feature comes from Stimuler's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Stimuler. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
